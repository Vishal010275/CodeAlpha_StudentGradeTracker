# Student Grade Tracker

## Project Overview
Student Grade Tracker is a Java-based application that manages student records, calculates average marks, identifies the highest and lowest marks, and assigns grades.

## Features
- Add student details and marks
- Calculate average marks
- Find highest and lowest marks
- Assign grades based on average marks
- Display all student records
- Search students using their IDs
- Generate a class performance summary
- Validate marks between 0 and 100

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Arrays
- Loops and Methods

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open `StudentGradeTracker.java`.
4. Run the `main()` method.
