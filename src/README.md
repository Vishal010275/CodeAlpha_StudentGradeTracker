# Student Grade Tracker

## Project Overview
Student Grade Tracker is a Java-based application that helps manage student records and analyze academic performance.

## Features
- Add student details and marks.
- Calculate average marks.
- Find highest and lowest marks.
- Assign grades based on average marks.
- Display all student records.
- Search students using their IDs.
- Generate a class performance summary.
- Validate marks between 0 and 100.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Arrays
- Loops and Methods

## Grade Criteria

| Average Marks | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 40–59.99 | D |
| Below 40 | F |

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open StudentGradeTracker.java.
3. Run the main() method.
4. Follow the console menu.

## Data Storage
Student records are stored in memory and are cleared when the application exits.
